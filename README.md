# RentHub Online Rental Platform

Five-file static website.

## Files
1. index.html
2. style.css
3. script.js
4. README.md
5. LICENSE.txt

## Run
Extract the ZIP and open index.html in Chrome, Edge, Firefox, or another browser.

## HTTPS
This is a static website and can be deployed to an HTTPS-enabled host such as GitHub Pages, Netlify, or another static hosting provider. HTTPS is provided by the host/domain configuration.

## Note
This demo has front-end search, category filtering, rental-request buttons, and a listing form. A real rental platform needs a backend, database, authentication, payments, and server-side security.
